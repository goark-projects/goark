# Goark Core 0.0.1

English | [中文](https://github.com/goark-projects/goark/blob/v0.0.1/docs/releases/v0.0.1.zh-CN.md)

Release date: September 6, 2026

Goark Core 0.0.1 is the first public release of the framework runtime. It
provides explicit dependency injection, configuration, lifecycle, events, and
Go-native Web contracts while leaving startup conventions to `goark.dev/boot`
and compile-time discovery to `goark.dev/cli`.

See the [changelog](https://github.com/goark-projects/goark/blob/v0.0.1/CHANGELOG.md#001---2026-09-07)
for the concise version history.

## :star: New Features

- Add explicit bean registration, resolution, aliases, scopes, dependency
  ordering, application context refresh, and deterministic shutdown.
- Add layered configuration environments, conversion, placeholders,
  configuration-property contracts, and safe expressions.
- Add MVC and Web runtime contracts for controllers, binding, validation,
  advice, filters, views, static resources, streams, WebSocket, tests, and
  outbound clients.

## :information_source: Design Boundary

- Runtime classpath scanning and dynamic proxies are intentionally excluded.
- Boot owns startup conventions; CLI owns deterministic generated registration.
- Arkarta owns enterprise Web standards and container TCK contracts.

## :package: Installation

```bash
go get goark.dev/goark@v0.0.1
```

Go 1.26 or later is required.

## :white_check_mark: Verification

The candidate passed tests, vet, and race tests on Windows Go 1.26 and Debian
Linux Go 1.27. CI repeats formatting, module, test, vet, and race gates on
Linux, Windows, and macOS.
