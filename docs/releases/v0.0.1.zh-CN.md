# Goark Core 0.0.1

[English](https://github.com/goark-projects/goark/blob/v0.0.1/docs/releases/v0.0.1.md) | 中文

发布日期：2026 年 9 月 6 日

Goark Core 0.0.1 是框架运行时的首个公开版本。它提供显式依赖注入、配置、
生命周期、事件和 Go 原生 Web 契约，同时由 `goark.dev/boot` 负责启动约定，
由 `goark.dev/cli` 负责编译期发现。

精简版本历史见[变更日志](https://github.com/goark-projects/goark/blob/v0.0.1/CHANGELOG.zh-CN.md#001---2026-09-07)。

## :star: 新功能

- 新增显式 Bean 注册、解析、别名、Scope、依赖顺序、应用上下文刷新和确定性关闭。
- 新增分层配置环境、类型转换、占位符、配置属性契约和安全表达式。
- 新增 MVC 与 Web 运行时契约，覆盖 Controller、绑定、校验、Advice、Filter、
  视图、静态资源、流式响应、WebSocket、测试和出站 Client。

## :information_source: 设计边界

- 明确不使用运行时 classpath 扫描和动态代理。
- Boot 负责启动约定；CLI 负责确定性的生成式注册。
- Arkarta 负责企业级 Web 标准和容器 TCK 契约。

## :package: 安装

```bash
go get goark.dev/goark@v0.0.1
```

要求 Go 1.26 或更高版本。

## :white_check_mark: 验证

候选版本已在 Windows Go 1.26 和 Debian Linux Go 1.27 上通过测试、vet 和 race。
CI 会在 Linux、Windows 和 macOS 上重复执行格式、模块、测试、vet 和 race 门禁。
